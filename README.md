# Реакции

[Открыть демо](https://gallery-test-duckpluck.netlify.app)

Интерактивное демо: четыре кучки по восемь зацикленных видео, увеличение при приближении курсора и распределение четырёх эмоций. На телефоне просмотр открывается нажатием, панель ответов закреплена снизу.

Наведение на любой из 32 исходных роликов увеличивает его. Клик открывает дополнительную подборку из 4 до 8 связанных видео. Она остаётся открытой при движении курсора; повторный клик по исходному ролику, нажатие вне подборки, Escape или кнопка закрытия закрывают её. На телефоне подборка открывается нажатием. Фокус клавиатуры увеличивает ролик, Enter или Space открывают подборку и переводят фокус внутрь. Escape и кнопка закрытия возвращают его к исходному ролику. Одновременно открыта одна подборка.

Свободное сопоставление без оценки и отправки данных. Ответы можно менять, переносить между слотами и сбрасывать. Перезагрузка начинает новую попытку.

## Запуск

Нужен Node.js 20 или новее.

```sh
npm ci
npm start
```

Открыть http://localhost:4173. Сайт статический, файлы для публикации находятся в `site/`. Сервер разработки поддерживает диапазоны байтов для видео и не нужен в продакшене.

## Видео

В репозитории уже есть четыре MP4-заглушки и постеры. В каждой группе восемь независимых плееров с разной фазой. Ролики длиной 3 секунды, 240 × 320, H.264, без аудиодорожки. Их можно заново подготовить через `npm run media`; FFmpeg устанавливается как инструмент разработки.

Чтобы подключить актёрские реакции, замените записи в `site/media.js`: у каждого ролика есть `id`, `src`, `poster`, `phase` от 0 до 1 и доступное имя `label`. Положите файлы в `site/videos/` и `site/posters/`. Уменьшенная анимация по умолчанию останавливает видео. Невидимые плееры и скрытая вкладка приостанавливаются; кнопка общей паузы сохраняет приоритет.

Поле `related` каждого исходного ролика содержит его подборку из 4 до 8 записей с такими же полями видео. В демо используются те же локальные материалы с разными фазами. Дополнительная группа переиспользует не более восьми плееров. При закрытии они приостанавливаются и убираются со страницы.

## Проверки

```sh
npm test
npx playwright install chromium firefox webkit
npm run test:browser
```

Тесты проверяют все 209 допустимых состояний распределения, замену, обмен, отмену переноса, сброс, клавиатуру, сенсорные нажатия, увеличение карточек, работу видео, ошибки загрузки, reduced motion, контраст через axe и ширины от 280 до 1440 px. Сенсорное перетаскивание и автопрокрутка дополнительно проверяются настоящими touch-событиями через Chromium CDP.

Полный прогон WebKit пока не проходит стабильно: в текущем Linux-окружении встречаются таймауты перезагрузки и управления видео. Раскрытие дополнительных групп проверено отдельно; успешный полный прогон WebKit и проверка на настоящем iPhone пока не подтверждены.

При запущенном локальном сервере:

```sh
npm run test:ui
```

Команда запускает проверки состояний, адаптивности, клавиатуры, целей нажатия, axe и reduced motion из `ux-ui-agent-skills@3.0.0`. Результаты и скриншоты сохраняются в игнорируемом каталоге `artifacts/`.

Проверки набора принимают локальный HTML. Для них скрипт составляет временный HTML из тех же исходников с inline CSS и модулем, чтобы избежать блокировки `file://` imports. Адаптер `scripts/gate-browser.mjs` направляет жёстко заданный в наборе канал системного Chrome на установленный полный Chrome for Testing. Правила, пороги и обязательность браузера не меняются.

UX/UI основан на [design-doctrine](https://github.com/plugin87/ux-ui-agent-skills/blob/main/.claude/skills/design-doctrine/SKILL.md) и [vanilla CSS](https://github.com/plugin87/ux-ui-agent-skills/blob/main/frameworks/adapters/vanilla-css.md). Тема находится в `site/theme.css`, без библиотек во время работы сайта.

## Netlify

Проект `gallery-test-duckpluck` подключён к `DuckPluck/gallery-test`: ветка `main`, каталог публикации `site/`, без команды сборки. Обновления основной ветки публикуются автоматически. Заголовки безопасности заданы в `netlify.toml`.

Для ручного деплоя из авторизованного аккаунта:

```sh
npx netlify-cli login
npx netlify-cli init
npx netlify-cli deploy --prod --dir=site --no-build
```

Состояние `.netlify/` и файлы окружения исключены из Git. Настоящий iPhone/Android и производительность актёрских видео требуют отдельной проверки после подключения материалов.
